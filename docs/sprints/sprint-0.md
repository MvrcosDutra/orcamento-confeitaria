## Definição de pronto (DoD)

Um item só vai para **Concluído** quando:
- o código compila e `mvn test` passa;
- tem teste unitário cobrindo as regras implementadas;
- entrou na branch `main` por pull request revisado por outro integrante;
- a issue foi fechada com o link do PR.
